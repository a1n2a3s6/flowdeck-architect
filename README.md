An interactive **System Design & Cloud Architecture Simulator** right in your browser. Design distributed systems visually, simulate live traffic from 100 to 10,000 RPS, inject Chaos Engineering node failures to test resilience, monitor real-time latency and cloud costs, and export directly to **Mermaid.js**, **SVG**, or **PNG**.

## Live Demo
👉 **[Launch FlowDeck Architect Live](https://a1n2a3s6.github.io/flowdeck-architect/)**

## Key Features
- **11 Cloud Infrastructure Components:** Drag and connect Clients, CDNs, Load Balancers, API Gateways, Microservices, Redis Caches, Databases, Message Queues, Object Storage, and AI/LLM Workers.
- **Live Animated Traffic Simulation:** Watch real-time request packets flow across your architecture with dynamic load bars, cache-hit short-circuiting, and automatic bottleneck detection.
- **Chaos Engineering Mode:** Click any server, cache, or database mid-simulation to crash it and immediately see cascading failures, error-rate spikes, or failover behavior.
- **Scale & Cost Telemetry:** Scale node replicas (`1x`–`10x`) and monitor live Throughput (RPS), p95 Latency, Error Rate, and estimated monthly cloud cost.
- **Ready-to-Run Templates:** Explore *High-Scale E-Commerce Microservices*, *AI RAG Chatbot Pipeline*, and *Global Video Streaming CDN* out of the box.
- **Instant Mermaid.js & Image Export:** Generate copy-paste Mermaid diagrams for documentation, or export high-resolution PNG, SVG, and JSON project files.

## Built With
- HTML5 & Interactive SVG Graph Engine
- Vanilla JavaScript (Traffic & Latency Simulation Engine)
- Tailwind CSS (CDN)
